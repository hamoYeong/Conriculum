# 여러 조건을 조합하기

## 목표

모두·하나 이상·부정의 의미를 &&·||·!로 표현하고 조합 사례를 설명한다.

공통 구조와 개인 지식 반영 규칙은 [[학습 체계/00 학습 체계 지도|학습 체계 지도]]를 따른다.

## 방향잡기

[학습 나침반]

### 이번 판단의 나침반

<!-- section: section-ch04-page05-compass; activity: activity-ch04-page05-compass -->

- 이전 연결: 각 비교 질문의 경계를 확인했다. 이제 작은 Bool 질문을 연결해 전체 조건을 만든다.
- 핵심 질문: 두 기준은 모두 필요한가, 하나라도 충분한가?
- 첫 예상: 회원이지만 금액 기준을 못 채웠을 때 “회원이면서 금액 기준 이상”과 “회원이거나 금액 기준 이상”의 답을 예상한다.
- 초기 확신: 낮음 | 중간 | 높음과 지금 그렇게 예상한 이유를 남긴다.
- 완료 증거:
  - 네 경우의 판단
  - 조합 연산자 선택 이유
  - 부정 범위 설명

## 탐색

[상황 제시]

<!-- section: section-ch04-page05-situation -->

- 제목: 여러 조건을 조합하기
- 상황: 배송 혜택 대상은 회원이면서 금액 기준을 충족해야 한다. 별도 안내 대상은 회원이거나 쿠폰을 가진 사람으로, 둘 다인 사람도 포함한다.
- 자료:
  - 항목:
    - 자료 이름: 작은 질문
    - 내용:

      ```swift
      let isMember = true
      let meetsMinimum = false
      let hasCoupon = true
      ```
  - 항목:
    - 자료 이름: 조합 후보
    - 내용:

      ```text
      isMember && meetsMinimum
      isMember || hasCoupon
      !(isMember || hasCoupon)
      ```
- 첫 질문: 두 기준은 모두 필요한가, 하나라도 충분한가?

## 기준 발견

[판단 기준]

<!-- section: section-ch04-page05-criteria -->

- 기준 질문:
  - 규칙이 모두를 요구하는가 하나 이상을 요구하는가?
  - 둘 다 참일 때도 포함하는가?
  - 부정이 한 조건을 뒤집는가 괄호 전체를 뒤집는가?
- 적용 순서:
  - 첫 예상을 확인한다.
  - 자료를 기준 질문으로 살펴본다.
  - 새 사례에 같은 기준을 적용하고 이유를 설명한다.
- 주의점: ||는 둘 다 참인 경우도 참이다. 복합 질문을 부정할 때 괄호로 범위를 보인다. 이번에는 부작용 없는 Bool 값의 의미만 다룬다.

## 적용

[자유 작성]

### 하나의 판단을 끝까지 설명하기

<!-- section: section-ch04-page05-work; activity: activity-ch04-page05-work -->

- 질문: a와 b를 false/false, false/true, true/false, true/true로 바꾸며 a && b, a || b, !(a || b)의 결과를 적고 두 안내 규칙에 연결한다.
- 입력 형식: a | b | 모두 | 하나 이상 | 둘 다 아님, 이어서 안내 규칙의 코드와 이유
- 필수 근거:
  - 네 입력 조합
  - &&·||·! 결과
  - 둘 다 참인 사례
  - 부정 범위
- 제출 뒤 예시:

  ```text
  false/false → false, false, true
  false/true → false, true, false
  true/false → false, true, false
  true/true → true, true, false
  배송 혜택: isMember && meetsMinimum
  안내 대상: isMember || hasCoupon
  !(a || b)는 두 조건 모두 거짓일 때만 참이다.
  ```
