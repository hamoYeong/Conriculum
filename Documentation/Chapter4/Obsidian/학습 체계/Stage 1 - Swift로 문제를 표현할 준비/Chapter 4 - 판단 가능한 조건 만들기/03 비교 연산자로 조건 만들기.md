# 비교 연산자로 조건 만들기

## 목표

같음·다름·크기 관계를 Swift 비교 연산자로 옮기고 Bool 결과를 설명한다.

공통 구조와 개인 지식 반영 규칙은 [[학습 체계/00 학습 체계 지도|학습 체계 지도]]를 따른다.

## 방향잡기

[학습 나침반]

### 이번 판단의 나침반

<!-- section: section-ch04-page03-compass; activity: activity-ch04-page03-compass -->

- 이전 연결: 비교식이 Bool을 만든다는 것을 확인했다. 이제 입력 사이의 관계에 맞는 기호를 고른다.
- 핵심 질문: 자연어가 묻는 관계를 어떤 비교 연산자로 표현할까?
- 첫 예상: 참여자가 정확히 4명인지 확인할 때 =와 == 중 무엇을 쓸지 이유와 함께 예상한다.
- 초기 확신: 낮음 | 중간 | 높음과 지금 그렇게 예상한 이유를 남긴다.
- 완료 증거:
  - 관계에 맞는 비교식
  - 평가한 Bool
  - 연산자 선택 근거

## 탐색

[상황 제시]

<!-- section: section-ch04-page03-situation -->

- 제목: 비교 연산자로 조건 만들기
- 상황: 독서 모임은 정확히 4명이 한 묶음을 신청한다. 현재 참여자는 4명이고 정원은 6명이다.
- 자료:
  - 항목:
    - 자료 이름: 입력
    - 내용:

      ```swift
      let participantCount = 4
      let capacity = 6
      ```
  - 항목:
    - 자료 이름: 관계 후보
    - 내용: == 같음 · != 다름 · < 미만 · > 초과 · <= 이하 · >= 이상
- 첫 질문: 자연어가 묻는 관계를 어떤 비교 연산자로 표현할까?

## 기준 발견

[판단 기준]

<!-- section: section-ch04-page03-criteria -->

- 기준 질문:
  - 비교할 양쪽 값은 무엇인가?
  - 같음·다름·크기 중 어느 관계인가?
  - 표현식의 결과를 true 또는 false로 말할 수 있는가?
- 적용 순서:
  - 첫 예상을 확인한다.
  - 자료를 기준 질문으로 살펴본다.
  - 새 사례에 같은 기준을 적용하고 이유를 설명한다.
- 주의점: let count = 4에서 =는 초기값을 설정한다. count == 4는 같음을 비교한다. 서로 다른 단위의 값은 같은 숫자처럼 비교하지 않는다.

## 적용

[자유 작성]

### 하나의 판단을 끝까지 설명하기

<!-- section: section-ch04-page03-work; activity: activity-ch04-page03-work -->

- 질문: 정확히 4명, 4명이 아님, 정원보다 적음, 정원을 넘음이라는 네 질문을 코드로 쓰고 현재 입력의 결과를 설명한다.
- 입력 형식: 질문 → 비교식 → Bool 결과 → 이유
- 필수 근거:
  - 네 비교식
  - true·false 결과
  - =와 ==의 차이
- 제출 뒤 예시:

  ```text
  participantCount == 4 → true
  participantCount != 4 → false
  participantCount < capacity → true
  participantCount > capacity → false
  =는 선언의 초기값을 정하고 ==는 두 값이 같은지 판단한다.
  ```
