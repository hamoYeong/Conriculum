# Chapter 4 지도

## 목적과 사고 행동의 변화

자연어 규칙을 참·거짓 질문과 Bool 조건으로 바꾸고, 경계·조합·반례와 의미 단위 조각으로 판단 근거를 설명한다.

계산된 숫자를 바로 행동으로 연결하기 전에, 자연어가 정한 기준을 누구나 같은 답을 얻는 질문으로 만든다. 조건을 그럴듯하게 쓰는 데서 끝내지 않고, 경계와 일부 조건만 참인 입력으로 의미를 확인한다.

## 이전 결과와 다음 입력

- 이전: Chapter 3에서 만든 `totalCost`와 계산 흐름을 판단할 재료로 받는다.
- 이번: 질문 → Bool → 비교 → 경계 → 조합 → 이름 → 반례 → 전이 → 의미 단위 조각으로 진행한다.
- 다음: Chapter 5에서 `canEnter`처럼 완성된 Bool을 입력으로 받아 가능한 경우와 실행 결과를 나눈다.

## 학습 경계

Int·Bool의 명확한 값과 부작용 없는 비교·논리 표현식을 사용한다. `if`, `else`, 실행 분기, 함수, 옵셔널, 자동으로 갱신되는 상태는 이번 핵심 범위에 넣지 않는다. 저장된 Bool 결과와 다시 평가할 식의 차이는 이름 붙이기에서 짚는다.

## 완료 증거

- 모호한 규칙을 입력·기준·경계가 분명한 질문으로 바꾼다.
- 비교와 논리 조합을 코드로 만들고 Bool 결과를 설명한다.
- 경계 전후와 일부 조건만 참인 사례의 기대 결과를 규칙에서 먼저 정한다.
- 잘못된 조건의 반례를 찾고 수정 후 기존 사례를 다시 확인한다.
- 새 문제에서 독립적으로 수행하고, 마지막에는 비연속 코드를 판단 책임과 흐름·변경 영향으로 설명한다.
