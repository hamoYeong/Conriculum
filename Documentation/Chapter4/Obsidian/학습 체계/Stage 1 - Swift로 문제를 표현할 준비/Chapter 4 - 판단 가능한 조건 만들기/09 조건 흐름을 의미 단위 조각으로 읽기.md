# 조건 흐름을 의미 단위 조각으로 읽기

## 목표

떨어진 입력·비교·논리 조합·관찰을 판단 책임의 의미 단위 조각으로 묶고 변경 영향을 설명한다.

공통 구조와 개인 지식 반영 규칙은 [[학습 체계/00 학습 체계 지도|학습 체계 지도]]를 따른다.

## 탐색

<!-- section: section-ch04-page09-situation -->

- 상황: 체험 교실의 조건 코드에는 안내 문구와 서로 다른 판단의 입력이 섞여 있다. 코드를 역할에 따라 의미 단위 조각으로 나누어 읽는다. 한 조각에 떨어진 줄을 함께 넣어도 된다.
- 자료:
  - 항목:
    - 자료 이름: 이번 코드의 재료
    - 내용: 나이 12세, 보호자 동의 없음, 회원 자격 있음. 전체 코드는 아래 의미 단위 조각 읽기에서 한 번에 살펴본다.
- 첫 질문: 서로 떨어진 코드가 함께 어떤 판단을 만들고 다음 판단에 무엇을 넘길까?

## 기준 발견

[판단 기준]

<!-- section: section-ch04-page09-criteria -->

- 기준 질문:
  - 함께 어떤 질문에 답하는 요소들인가?
  - 어느 조각의 Bool 결과가 다음 조각의 입력인가?
  - 조건 만들기와 결과 관찰은 어떤 책임이 다른가?
- 적용 순서:
  - 첫 예상을 확인한다.
  - 자료를 기준 질문으로 살펴본다.
  - 새 사례에 같은 기준을 적용하고 이유를 설명한다.
- 주의점: 조각은 연속된 줄이나 선언 종류로만 정하지 않는다. 하나의 정답 이름이나 조각 수로 이해를 평가하지 않는다.

## 적용

[의미 단위 조각 읽기]

### 하나의 판단을 끝까지 설명하기

<!-- section: section-ch04-page09-work; activity: activity-ch04-page09-work -->

- 코드:

  ```swift
  let age = 12
  let bannerText = "토요일 체험 교실"
  let hasConsent = false
  let isAgeEligible = age >= 12 && age <= 18
  let isMember = true
  let hasPermission = hasConsent || isMember
  let canEnter = isAgeEligible && hasPermission
  print(canEnter)
  ```
- 언어: swift
- Chapter 판단 렌즈:
  - 함께 어떤 질문에 답하는 요소들인가?
  - 어느 조각의 Bool 결과가 다음 조각의 입력인가?
  - 조건 만들기와 결과 관찰은 어떤 책임이 다른가?
- 조각 후보:
  - 항목:

  - 항목:

  - 항목:
    - 항목 ID: p09-element-3
    - 내용: let hasConsent = false
  - 항목:

  - 항목:
    - 항목 ID: p09-element-6

  - 항목:

  - 항목:
    - 항목 ID: p09-element-8
    - 내용: print(canEnter)
- 묶기: 떨어진 요소를 복수 선택해 같은 판단 책임의 조각으로 묶는다. 선택한 요소가 함께 답하는 질문을 설명한다.
- 조각 이름: 문법 이름 대신 무엇을 판단하는지 드러나는 조각 이름을 쓴다.
- 흐름 연결: 나이·권한 판단의 결과가 canEnter와 print로 이어지는 흐름을 자신의 조각 사이에 표시한다.
- 경계 설명: bannerText를 포함하거나 제외한 이유와 판단·관찰 책임의 경계를 설명한다.
- 변경 예측: isMember를 false로 바꾸면 어떤 조각과 결과가 달라지는가? age를 11로 바꾼 경우와 비교하고, Chapter 5에서 이 결과로 무엇을 결정할 수 있는지 적는다.
- 완료 증거:
