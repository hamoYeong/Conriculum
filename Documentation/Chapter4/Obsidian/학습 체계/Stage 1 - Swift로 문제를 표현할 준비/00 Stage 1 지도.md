# Stage 1 지도

## 목적

Stage 1은 **컴퓨팅 사고력을 얻기 위해 Swift를 도구로 사용할 준비를 마치는 단계**다. 비선형적인 Swift 지식 전체를 한꺼번에 익히지 않고, 문제를 표현하는 토대가 되는 일부 지식을 선형적인 챕터 순서로 학습한다.

## 지식 체계와 함께 진행하는 방법

각 챕터는 전체 지식 체계의 일부 개념을 소유하지 않고 현재 사고 행동에 맞게 연결해 사용한다. 학습자는 챕터를 지나며 기본 개념을 자신의 말로 설명하고, 자신의 문제와 예시를 붙이며, 개념 사이에 자신에게 의미 있는 관계를 만든다.

```text
Stage 1의 선형 챕터
→ 챕터별로 필요한 지식 선택
→ 수행과 판단 설명 기록
→ 학습자가 확인한 개인 표현과 관계 저장
→ 다음 챕터에서 다시 사용하고 수정
```

Stage 완료는 개인 표현의 개수나 관계 수가 아니라 새 문제를 구조화·표현·검증하고 판단을 설명한 수행 증거로 판단한다. 개인 지식은 학습자의 이해가 어떻게 변해 왔는지 보여 주는 별도의 결과물이다.

## Stage 1의 누적 코드 읽기 목표

Stage 1을 마칠 때 학습자는 코드를 토큰·문법·한 줄씩만 읽지 않고, **주요 개념이 함께 수행하는 의미 단위 조각**으로 읽을 수 있어야 한다. 조각은 물리적으로 연속된 줄일 필요가 없으며, 같은 데이터·판단·실행 흐름을 만드는 떨어진 요소를 함께 포함할 수 있다.

각 Chapter는 그 Chapter의 핵심 판단 렌즈로 코드를 다시 읽는 기회를 제공한다.

- Chapter 1: 문제 설명과 코드에서 입력·규칙·출력 조각을 찾는다.
- Chapter 2: 선언들을 값·타입·이름·변경 약속·표기와 역할의 묶음으로 읽는다.
- Chapter 3~7: 계산, 조건, 경우, 함수 책임, 검증 흐름에 맞춰 서로 떨어진 코드의 관계를 점진적으로 넓혀 읽는다.
- Final Chapter: 여러 Chapter의 조각을 입력에서 검증된 출력까지 이어진 하나의 문제 해결 흐름으로 설명한다.

수행 증거는 조각의 경계, 역할 이름, 요소 사이의 흐름, 한 요소가 바뀌 때의 영향을 설명한 기록으로 판단한다. 조각 수나 정해진 모범 이름과의 일치를 점수화하지 않는다.
