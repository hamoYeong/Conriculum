# 변하지 않는 값을 선언하기

> 페이지 목표: 현재 책임과 시간 범위에서 재할당이 필요한지를 판단해 `let`과 `var`를 선택한다.

## 방향잡기

[학습 나침반]

- 이전 연결: 값의 역할을 이름에 남겼다. 이제 그 이름이 현재 범위에서 다른 값을 다시 가리킬 수 있는지 약속한다.
- 핵심 질문: 누가, 언제, 어느 범위에서 같은 이름에 새 값을 넣어야 하는가?
- 첫 예상: 장바구니 편집 중의 수량과 결제 계산에 전달된 수량을 각각 `let` 또는 `var`로 고른다.
- 초기 확신: 낮음 | 중간 | 높음과 선택 이유를 적는다.
- 완료 증거: 같은 정보가 다른 책임 범위에서 `let`과 `var`로 달라지는 예를 만들고 주체·시점·범위를 설명한다.

## 탐색

[상황 제시]

- 제목: 장바구니 편집과 결제 계산의 경계
- 상황: 사용자는 장바구니에서 수량을 바꾸지만, 결제 버튼을 누른 뒤 계산에 전달된 수량과 금액은 바꾸지 않는다.
- 자료: 장바구니 편집 → 주문 확인 → 결제 계산 → 결제 완료
- 첫 질문: 수량이 현실에서 바뀌 수 있다는 이유만으로 결제 계산 안의 수량도 `var`여야 할까?

[선택 후 설명]

- 질문: 편집 중의 `editingQuantity`와 결제 계산에 전달된 `quantity`의 선언 키워드를 고른다.
- 선택지: `let` | `var`
- 이유 입력: `누가 → 언제 → 어느 범위에서 → 재할당하는가`를 적는다.
- 판단 피드백: `나중에 바뀌 수 있다`는 답에는 현재 선언을 소유한 책임이 직접 바꾸는지 되묻는다.

[개념 대조]

- 비교 기준: 같은 이름에 새 값을 넣을 수 있는가?
- 항목: `let` → 처음 정한 뒤 같은 이름에 새 값을 재할당하지 않는다. | `var` → 현재 범위의 책임이 요구할 때 새 값을 재할당할 수 있다.
- 관찰 질문: 정보의 타입이 아니라 책임 범위가 선택을 어떻게 바꾸는가?

[개념 정의]

- 개념: 상수와 변수
- 한 문장 정의: `let` 상수는 한 번 정한 값을 같은 이름에서 유지하고, `var` 변수는 현재 범위에서 같은 이름에 새 값을 넣을 수 있다.
- 적용 범위: 우선 `let`을 선택하고, 현재 책임에 구체적인 재할당 요구가 있을 때 `var`를 검토한다.
- 지식 링크: [[지식 체계/02 값과 타입/상수와 변수|상수와 변수]]

[판단 기준]

- 기준 질문: 이 선언의 책임은 어디까지인가? 누가 언제 새 값을 넣는가? 재할당하지 않고 새 선언으로 넘겨도 되는가?
- 적용 순서: 책임 범위 → 재할당 주체·시점 → `let` 우선 → 필요할 때 `var`
- 주의점: `let`은 현실의 대상이 영원히 변하지 않는다는 주장이 아니라 현재 이름의 재할당 약속이다.

[지식 연결]

- 지식 링크: [[지식 체계/02 값과 타입/상수와 변수|상수와 변수]], [[지식 체계/01 문제 해결과 컴퓨팅 사고/문제의 경계|문제의 경계]]
- 이 페이지에서의 쓰임: 정보의 영구성이 아니라 현재 선언의 변경 책임을 판단한다.
- 표시 시점: 첫 선택 뒤에 펼친다.

[코드 조립]

- 시작 코드:

```swift
___ editingQuantity = 2
___ quantity = editingQuantity
___ orderAmount = 20_000
```

- 조각: `let` | `var`
- 고정 부분: 식별자, 등호, 오른쪽 값
- 완료 조건: 편집과 계산 범위를 먼저 표시한 뒤 세 선언을 완성하고, 각 선택에 재할당 주체·시점·범위를 남긴다.

## 성찰

[학습 마무리]

- 첫 예상: 편집 수량·결제 수량에 대한 최초 선택
- 최종 설명: 같은 정보가 다른 범위에서 `let`과 `var`로 달라진 근거
- 확신 변화: 낮음 | 중간 | 높음을 다시 고르고 구체적인 주체·시점·범위를 증거로 적는다.
- 바뀐 기준: `현실에서 바뀔 수 있다`에서 `현재 책임 안에서 다시 대입해야 한다`로 어떻게 바뀌었는지 적는다.
- 다음에 쓸 장소: Swift가 알아낸 타입과 직접 적은 타입의 역할을 비교한다.

- 확인 질문: `let`과 `var`를 값의 종류가 아니라 변경 책임으로 선택할 수 있는가?
- 필요한 증거: 같은 정보의 `let`·`var` 선언 한 쌍, 각 선언의 범위·주체·시점
- 다시 시도 조건: `나중에 바뀌 수 있다`만 근거라면 누가 어느 범위에서 재할당하는지 구체화한다.
