# Chapter 3 Overview

> Chapter 목표: 이름 붙은 값을 표현식으로 연결해 새로운 값을 만들고, 입력·중간값·결과·관찰이 이어지는 계산 조각을 설명한다.

## 방향잡기

[학습 나침반]

- 이전 연결: Chapter 2에서 현실의 정보를 Swift 선언으로 준비했다. 이제 그 값들 사이의 관계를 코드로 계산한다.
- 핵심 질문: 여러 입력값은 어떤 관계를 거쳐 하나의 새로운 결과값이 될까?
- 첫 예상: 아래 코드에서 입력값, 계산 관계, 결과값을 아는 만큼 표시한다.
- 초기 확신: 낮음 | 중간 | 높음과 이유를 한 문장으로 남긴다.
- 완료 증거: 새 문제의 계산식을 만들고, 떨어진 입력·중간값·결과·print를 의미 단위 조각으로 묶어 이름·흐름·변경 영향을 설명한다.

## 탐색

[상황 제시]

- 제목: 독서 모임 준비 비용 계산
- 상황: 책 네 권의 가격과 배송비로 전체 준비 비용을 계산해 보여 주려 한다.
- 자료:

```swift
let participantCount = 4
let bookPrice = 18_000
let deliveryFee = 3_000
let bookSubtotal = participantCount * bookPrice
let totalCost = bookSubtotal + deliveryFee
print(totalCost)
```

- 첫 질문: 여섯 줄을 선언 종류나 줄 순서가 아니라 계산에서 맡은 역할로 나누면 어떻게 보이는가?

[개념 대조]

- 비교 기준: 연산 기호를 순서대로 읽기 | 값이 새 값으로 변하는 흐름 읽기
- 항목:
  - `participantCount`와 `bookPrice`는 책 금액을 만드는 입력이다.
  - `bookSubtotal`은 큰 계산의 한 단계를 설명하는 중간값이다.
  - `deliveryFee`는 떨어져 선언되어 있어도 `totalCost`를 만드는 입력이다.
  - `print`는 결과를 만들지 않고 계산된 값을 관찰한다.
- 관찰 질문: `participantCount`가 바뀌면 어느 중간값과 결과가 차례로 달라지는가?

[과정 안내]

- 단계:
  1. **관계·표현 1~3:** 입력과 결과의 관계를 찾고 표현식과 산술 연산으로 쓴다.
  2. **계산 구조 4~6:** 중간값, 평가 순서와 수 타입으로 결과가 만들어지는 과정을 설명한다.
  3. **관찰·전이 7~8:** 실행 전 예상과 실제 결과를 비교하고 새 문제에 적용한다.
  4. **의미 단위로 읽기 9:** 떨어진 입력·변환·결과·관찰을 책임과 흐름으로 묶는다.
- 완료 모습: 결과 숫자만 맞히는 데서 멈추지 않고 어떤 입력이 어느 단계를 거쳐 결과를 만들었는지 설명한다.
