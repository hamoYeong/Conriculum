# 계산 흐름을 의미 단위 조각으로 읽기

> 페이지 목표: 떨어져 있고 섞여 있는 입력 선언·표현식·중간값·결과·관찰을 계산 책임의 의미 단위 조각으로 묶고 데이터 흐름과 변경 영향을 설명한다.

## 방향잡기

[학습 나침반]

- 이전 연결: 8페이지에서 여행 비용 계산을 순서대로 만들었다. 이제 코드의 물리적 순서를 바꾸어도 같은 계산 책임을 복원한다.
- 핵심 질문: 떨어진 코드 요소들은 함께 어떤 값을 만들고 다음 조각에 무엇을 넘기는가?
- 첫 예상: 아래 코드에서 연속된 줄을 기준으로 하지 않고 계산 조각 경계를 표시한다.
- 초기 확신: 낮음 | 중간 | 높음과 이유를 남긴다.
- 완료 증거: 비연속 요소를 포함한 조각 두 개 이상에 역할 이름을 붙이고, 흐름·제외 근거·변경 영향을 설명한다.

## 탐색

[상황 제시]

- 제목: 섞여 있는 독서 모임 계산 코드
- 상황: 계산 입력, 화면 문구, 중간값과 출력이 파일에서 섞여 있다고 가정한다.
- 자료:

```swift
let deliveryFee = 3_000
let participantCount = 4
let bannerText = "이번 달 독서 모임"
let totalCost = bookSubtotal + deliveryFee
let bookPrice = 18_000
print(totalCost)
let bookSubtotal = participantCount * bookPrice
```

- 첫 질문: 줄 순서대로 실행할 수 없는 이 코드에서도 어떤 요소가 같은 계산 책임에 속하는지는 찾을 수 있는가?

[개념 대조]

- 비교 기준: 붙어 있는 줄·같은 선언 문법 | 같은 결과에 기여하는 책임과 흐름
- 항목: `participantCount`와 `bookPrice`는 떨어져 있지만 `bookSubtotal`을 만든다 | `bookSubtotal`, `deliveryFee`, `totalCost`는 최종 비용을 만든다 | `print(totalCost)`는 결과 계산이 아니라 관찰 책임이다 | `bannerText`는 같은 선언 문법이어도 계산 흐름에서 제외된다
- 관찰 질문: 한 요소가 중간 결과이자 다음 조각의 입력으로 두 조각을 연결할 수 있는가?

[판단 기준]

- 기준 질문: 함께 어떤 결과를 만드는가? 한 요소의 결과가 다음 요소의 입력인가? 이 요소가 사라지면 어느 결과가 달라지는가? 같은 선언 문법이어도 책임이 다른가?
- 적용 순서: 문제와 예상 결과 → 역할 표시 → 비연속 요소 묶기 → 조각 이름 → 흐름 연결 → 변경 영향
- 주의점: 코드의 현재 물리적 순서와 실행 가능한 순서를 구분하고, 조각 경계 하나만 정답으로 가정하지 않는다.

[의미 단위 조각 읽기]

- 조각 후보: 책값 합계를 만든다 | 전체 비용을 만든다 | 결과를 관찰한다 | 화면 제목을 준비한다
- 묶기: 물리적으로 떨어진 요소를 복수 선택해 조각 후보에 연결한다. `bookSubtotal`은 첫 조각의 결과이자 둘째 조각의 입력으로 연결할 수 있다.
- 조각 이름: `책 수량과 가격으로 책값 합계를 만든다`처럼 입력·행동·결과가 드러나게 작성한다.
- 흐름 연결: `participantCount + bookPrice → bookSubtotal → + deliveryFee → totalCost → print`의 데이터 흐름을 표시한다.
- 변경 예측: `participantCount`가 `5`로 바뀌면 어느 조각의 결과가 차례로 달라지고 `bannerText`는 왜 그대로인지 설명한다.
- 완료 증거: 조각 두 개 이상, 비연속 요소 연결, 제외 근거, 조각 사이 흐름, 변경 영향

[자유 작성]

- 과제: 자신이 만든 계산 조각 하나를 코드를 보지 못한 사람에게 설명한다.
- 입력 형식: `조각 이름 → 입력 요소 → 관계 → 결과 → 다음 조각 → 변경 영향`
- 필수 근거: 떨어진 요소 하나와 다른 책임이라 제외한 요소 하나를 포함한다.
- 제출 뒤 예시: `전체 비용을 만든다 → bookSubtotal, deliveryFee → 더한다 → totalCost → 관찰 조각 → participantCount가 바뀌면 bookSubtotal을 거쳐 totalCost도 바뀐다.`
