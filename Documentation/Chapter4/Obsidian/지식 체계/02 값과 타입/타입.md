# 타입

## 한 문장 정의

타입은 값이 어떤 종류의 정보이며 어떤 연산과 사용이 허용되는지를 정하는 약속이다.

## 구분 질문

이 값은 무엇을 나타내며 프로그램에서 어떤 일을 할 수 있는가?

## 판단 순서와 기준

- 글자, 정수, 소수, 참·거짓 중 어떤 성격인가?
- 이후 계산·비교·표시·판단 중 어떤 일을 해야 하는가?
- 같은 모양이라도 의미와 사용 목적이 다른가?
- 현재 타입이 표현하지 못하는 상태가 있는가?

## 대표 예시와 경계

`20_000`은 보통 `Int`, `"20,000원"`은 `String`이다. 둘은 비슷한 내용을 보여 줄 수 있지만 전자는 계산에, 후자는 글자 표시에 맞는다.

## 오해와 교정

- 오해: 타입은 값을 보관할 상자의 이름일 뿐이다. → 교정: 타입은 허용할 값과 연산을 제한하며 의도를 전달한다.
- 오해: 화면에 보이는 모양만 보고 타입을 고른다. → 교정: 내부에서 할 계산·비교·판단과 허용할 상태를 함께 본다.
- 오해: 기본 타입 하나로 현실의 의미를 모두 설명할 수 있다. → 교정: 여러 상태와 제약이 생기면 더 구체적인 사용자 정의 타입을 검토한다.
