# String

## 한 문장 정의

`String`은 글자들의 순서를 하나의 텍스트 값으로 표현하는 Swift 타입이다.

## 구분 질문

이 정보는 문자 내용과 순서를 그대로 보존하고 다루어야 하는가?

## 판단 순서와 기준

- 숫자처럼 보여도 계산보다 글자 자체가 중요한가?
- 여러 문자로 이루어진 이름, 제목, 설명인가?
- `""` 안에 적은 문자열 리터럴인가?

## 대표 예시와 경계

닉네임 `"푸른고래"`, 책 제목 `"Swift 시작하기"`, 우편번호 `"01234"`는 글자 그대로의 모양이 중요하므로 `String`으로 표현할 수 있다. 반대로 주문 금액 `20_000`은 화면에 글자로 표시되더라도 내부에서 더하고 비교해야 하므로 처음부터 `String`으로 만들지 않는다.

## 오해와 교정

- 오해: 화면에 표시되는 모든 정보는 처음부터 `String`이어야 한다. → 교정: 내부에서 계산·판단할 값과 마지막 표시 형식을 분리한다.
- 오해: 숫자로만 된 글자는 언제나 `Int`다. → 교정: 우편번호처럼 모양과 앞자리 0을 보존하는 정보는 `String`이 더 맞다.
- 오해: 문자열 속 숫자를 바로 산술 계산에 쓸 수 있다. → 교정: 문자열과 수는 다른 타입이며, 변환 가능성과 실패를 따로 다뤄야 한다.
