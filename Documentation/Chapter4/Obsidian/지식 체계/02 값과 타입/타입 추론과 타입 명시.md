# 타입 추론과 타입 명시

## 한 문장 정의

타입 추론은 Swift가 주어진 표현에서 타입을 알아내는 기능이고, 타입 명시는 개발자가 선언에 타입을 직접 적어 제약과 의도를 드러내는 표기다.

## 구분 질문

타입을 Swift가 알아내게 둘 것인가, 선언에서 직접 보여 줄 것인가?

## 판단 순서와 기준

- 값만 보아도 의도한 타입이 분명한가?
- 문맥상 특정 타입이어야 한다는 약속을 드러내야 하는가?
- 타입을 적는 것이 이해를 돕는가, 이미 분명한 내용을 반복하는가?
- 추론 결과가 내가 의도한 타입과 같은가?

## 대표 예시와 경계

`let quantity = 2`에서 Swift는 `Int`를 추론한다. `let discountRate: Double = 0.1`은 비율을 `Double`로 다루겠다는 의도를 선언에 직접 남긴다.

## 오해와 교정

- 오해: 타입 추론은 타입이 없다는 뜻이다. → 교정: 타입은 존재하며 Swift가 문맥과 표현에서 알아낸다.
- 오해: 모든 선언에 타입을 적는 것이 더 안전하다. → 교정: 의도와 제약을 더 분명히 할 때 명시하고, 이미 분명하다면 반복을 줄인다.
- 오해: 타입을 명시하면 모호한 이름도 괜찮다. → 교정: 타입과 식별자는 서로 다른 정보를 전달하므로 둘 다 맥락에 맞게 판단한다.
