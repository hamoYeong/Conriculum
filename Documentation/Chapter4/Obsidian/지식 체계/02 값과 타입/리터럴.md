# 리터럴

## 한 문장 정의

리터럴은 소스 코드에 값을 직접 적는 표기다.

## 구분 질문

구체적인 값을 Swift 코드에 어떤 모습으로 적는가?

## 판단 순서와 기준

- 따옴표, 소수점, `true`·`false` 같은 표기가 값의 종류를 드러내는가?
- 숫자 구분용 밑줄을 제거해도 같은 값인가?
- 이름이 아니라 값 자체를 적은 부분인가?

## 대표 예시와 경계

`"푸른고래"`, `20_000`, `4.5`, `true`는 각각 문자열, 정수, 실수, 불리언 리터럴이다. `20_000`의 밑줄은 읽기 쉽게 할 뿐 값은 `20000`과 같다.

## 오해와 교정

- 오해: `"20_000"`과 `20_000`은 같은 종류의 값이다. → 교정: 따옴표가 있는 전자는 문자열, 후자는 정수 리터럴이다.
- 오해: 리터럴과 값을 가리키는 식별자는 같은 것이다. → 교정: 리터럴은 값을 직접 적는 표기이고 식별자는 그 값을 다시 가리킬 이름이다.
- 오해: 화면의 쉼표와 통화 단위를 숫자 리터럴에 그대로 넣는다. → 교정: 내부 수와 표시 형식을 분리한다.

## 유형이 있는 지식 관계

- 표현 대상: 리터럴은 [[지식 체계/02 값과 타입/값|값]]을 직접 나타낸다.
- 추론 단서: 표기는 [[지식 체계/02 값과 타입/타입|타입]]이 추론될 단서를 제공한다.
- 선언: 이름을 붙인 뒤에는 [[지식 체계/02 값과 타입/상수와 변수|상수나 변수]]에 저장할 수 있다.
