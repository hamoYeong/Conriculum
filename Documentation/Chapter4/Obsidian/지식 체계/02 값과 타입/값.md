# 값

## 한 문장 정의

값은 프로그램이 저장하거나 비교하거나 계산하거나 표시할 수 있도록 하나로 정해진 정보다.

## 구분 질문

현실의 정보 중 지금 프로그램이 직접 다룰 대상은 무엇인가?

## 판단 순서와 기준

- 하나의 구체적인 정보로 정해져 있는가?
- 프로그램이 이 정보를 저장·표시·계산·판단에 사용하는가?
- 이번 사례의 값과 여러 사례에 반복되는 규칙을 구분했는가?
- 값 자체와 값을 설명하는 화면 문구를 구분했는가?

## 대표 예시와 경계

한 주문의 닉네임 `"푸른고래"`, 수량 `2`, 결제 완료 여부 `true`는 값이다. “회원이면 할인한다”는 여러 값에 적용되는 규칙이므로 값 하나가 아니다.

## 오해와 교정

- 오해: 숫자만 값이다. → 교정: 텍스트, 참·거짓, 직접 정의한 타입의 사례도 프로그램이 다루는 값이 될 수 있다.
- 오해: 화면에 보이는 전체 문장이 언제나 하나의 값이다. → 교정: 문장을 이루는 정보와 표시용 문구를 분리해 각각의 역할을 찾는다.
- 오해: 아직 계산하지 않은 결과도 이미 주어진 값이다. → 교정: 주어진 입력과 규칙을 적용해 만들어야 할 출력을 구분한다.

## 유형이 있는 지식 관계

- 표현: 값은 코드에서 [[지식 체계/02 값과 타입/리터럴|리터럴]]로 직접 나타낼 수 있다.
- 제약: [[지식 체계/02 값과 타입/타입|타입]]은 그 값이 할 수 있는 일을 정한다.
- 문제 역할: 값의 역할을 찾는 일은 [[지식 체계/01 문제 해결과 컴퓨팅 사고/입력|입력]] 및 [[지식 체계/01 문제 해결과 컴퓨팅 사고/출력|출력]]과 연결된다.
