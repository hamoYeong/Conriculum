# 상수와 변수

## 한 문장 정의

상수는 한 번 정한 뒤 같은 이름에 다른 값을 넣지 않는 `let` 선언이고, 변수는 필요할 때 값을 다시 넣을 수 있는 `var` 선언이다.

## 구분 질문

현재 책임과 시간 범위 안에서 이 이름이 가리키는 값은 바뀌어야 하는가?

## 판단 순서와 기준

- 이 단계에서 값의 변경이 실제 요구사항인가?
- 변경이 필요 없다면 `let`으로 의도를 제한할 수 있는가?
- 다른 화면이나 더 긴 시간 범위의 변화와 현재 계산 안의 변화를 구분했는가?
- 값이 아니라 같은 이름이 다른 값을 가리키게 되는지를 묻고 있는가?

## 대표 예시와 경계

장바구니 편집 중 수량은 변할 수 있지만, 결제 계산을 시작한 순간 전달받은 주문 수량은 `let` 입력으로 고정할 수 있다. 판단 범위가 다르면 같은 정보의 변경 가능성도 달라진다.

## 오해와 교정

- 오해: 현실에서 바뀔 수 있는 정보는 언제나 `var`다. → 교정: 현재 코드가 책임지는 시간과 범위 안에서 다시 대입할 필요가 있는지 묻는다.
- 오해: 모든 값을 `var`로 두면 더 편하다. → 교정: 필요 없는 변경 가능성은 의도를 흐리고 실수의 범위를 넓힌다.
- 오해: `let`이면 값 내부의 모든 상태와 참조 의미까지 항상 불변이다. → 교정: `let`이 제한하는 것은 선언된 이름에 대한 재대입이며 값·참조 타입의 세부 의미는 따로 살핀다.
