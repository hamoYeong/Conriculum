# Bool

## 한 문장 정의

`Bool`은 `true`와 `false` 두 값으로 참·거짓 상태를 표현하는 Swift 타입이다.

## 구분 질문

이 정보는 지금 참인가 거짓인가라는 두 경우로 충분히 표현되는가?

## 판단 순서와 기준

- 예·아니오 질문 하나로 상태를 설명할 수 있는가?
- 참일 때 식별자와 함께 자연스럽게 읽히는가?
- 실제로는 세 가지 이상의 상태가 필요한 것은 아닌가?

## 대표 예시와 경계

회원 여부 `true`, 결제 완료 여부 `false`처럼 두 경우로 충분한 상태는 `Bool`로 표현할 수 있다. 결제 상태가 `대기·완료·실패`로 나뉜다면 `false` 하나에 대기와 실패를 섞지 말고 세 상태를 표현할 다른 타입을 검토한다.

## 오해와 교정

- 오해: 두 단어로 보이는 모든 상태는 `Bool`이다. → 교정: 실제로 가능한 상태가 정확히 두 개인지 먼저 확인한다.
- 오해: `"회원"`과 `true`는 같은 정보다. → 교정: 전자는 텍스트이고 후자는 참·거짓 판단값이다.
- 오해: 아직 정해지지 않음도 `false`에 넣으면 된다. → 교정: 미정이 의미 있는 상태라면 별도의 상태로 보존한다.
