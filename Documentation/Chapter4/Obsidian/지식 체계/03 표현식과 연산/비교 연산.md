# 비교 연산

## 한 문장 정의

비교 연산은 두 값의 관계를 확인해 Bool 결과를 만드는 연산이다.

## 구분 질문

어떤 관계를 확인하며 결과는 어떤 타입인가?

## 판단 순서와 기준

- 같음을 묻는가 크기를 묻는가?
- 두 값의 타입과 단위가 비교에 맞는가?
- 같음은 ==, 값에 이름을 붙이는 선언은 =로 구분했는가?

## 대표 예시와 경계

- totalCost >= 50_000은 기준 이상인지 묻는다.
- participantCount == 4는 네 명인지 묻고, participantCount != 4는 네 명이 아닌지 묻는다.
- Swift에서 조건을 만들 때 숫자 0을 false 대신 쓰지 않는다.

## 오해와 교정

- =와 ==를 같은 의미로 읽는다.
- 비교식 결과를 비교에 쓴 숫자 타입이라고 생각한다.
