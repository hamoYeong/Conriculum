# 산술 연산

## 한 문장 정의

산술 연산은 수 값을 합치고, 제외하고, 반복해 묶고, 나누는 관계를 `+`, `-`, `*`, `/`로 표현한다.

## 구분 질문

“구하려는 결과와 입력의 관계는 합침·차이·반복·분배 중 무엇인가?”

## 판단 순서와 기준

1. 구할 결과의 의미와 단위를 말한다.
2. 각 입력이 전체, 부분, 반복량, 묶음 수 중 어떤 역할인지 정한다.
3. 자연어 관계에 맞는 연산자를 고른다.
4. `-`와 `/`에서는 입력 순서가 결과 의미와 맞는지 확인한다.
5. 실행 전에 결과의 범위와 단위를 예상한다.

## 대표 예시와 경계

`bookSubtotal + deliveryFee`는 두 비용을 합치고, `budget - totalCost`는 기준 예산에서 사용 비용을 제외한다. `participantCount * bookPrice`는 같은 한 권 가격을 사람 수만큼 묶는다. 비교 연산과 논리 연산은 수량을 계산하기보다 참·거짓 조건을 만드는 다른 책임이다.

## 오해와 교정

- 오해: 문장에 `더`가 보이면 언제나 `+`다. → 교정: 구할 결과와 입력 역할을 함께 본다.
- 오해: 뺄셈과 나눗셈도 입력 순서가 중요하지 않다. → 교정: 기준량·제외량, 전체·묶음 크기의 역할을 표시한다.
- 오해: 연산자만 맞으면 설명이 끝난다. → 교정: 결과 의미, 단위와 타입까지 예상한다.
