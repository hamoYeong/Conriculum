# print로 관찰하기

## 한 문장 정의

`print`는 값을 계산하는 규칙이 아니라 이미 계산된 값이나 중간값을 실행 중에 확인하게 하는 관찰 도구다.

## 구분 질문

“어떤 값을 출력하면 예상과 실제가 처음 달라진 계산 단계를 가장 빨리 찾을 수 있는가?”

## 판단 순서와 기준

1. 실행 전에 관찰할 값의 결과를 예상한다.
2. 가장 이른 의미 있는 중간값을 먼저 출력한다.
3. 예상과 실제가 같으면 다음 결과값으로 이동한다.
4. 처음 달라진 값을 만든 입력과 표현식을 확인한다.
5. 문제를 찾은 뒤 불필요한 출력은 줄인다.

## 대표 예시와 경계

`print(bookSubtotal)`은 책값 계산 단계를, `print(totalCost)`는 최종 비용을 보여 준다. `print` 줄을 제거해도 앞의 표현식과 선언이 만든 값은 바뀌지 않는다. 사용자 인터페이스에 결과를 표시하는 설계는 별도의 책임이다.

## 오해와 교정

- 오해: print가 계산을 실행하거나 결과를 만든다. → 교정: 계산과 선언이 값을 만들고 print는 그 값을 보여 준다.
- 오해: 실제 출력부터 보고 예상은 나중에 맞춘다. → 교정: 예상과 실제의 차이가 학습·디버깅 증거가 되므로 예상을 먼저 기록한다.
- 오해: 모든 값을 출력할수록 원인을 빨리 찾는다. → 교정: 의미 있는 중간값부터 관찰해 정보 소음을 줄인다.
