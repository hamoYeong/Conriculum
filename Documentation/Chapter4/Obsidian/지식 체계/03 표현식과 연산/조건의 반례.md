# 조건의 반례

## 한 문장 정의

조건의 반례는 자연어 규칙이 요구한 판단과 작성한 조건식의 결과가 달라지는 입력이다.

## 구분 질문

이 조건이 틀렸음을 드러낼 입력은 무엇인가?

## 판단 순서와 기준

- 먼저 자연어 규칙으로 기대 결과를 정했는가?
- 경계나 일부 조건만 참인 경우를 골랐는가?
- 반례를 고친 뒤 원래 맞던 사례도 유지되는가?

## 대표 예시와 경계

- 10개 이상 규칙을 count > 10으로 썼다면 count = 10이 반례다.
- 회원이면서 금액 이상인데 ||로 썼다면 비회원·금액 이상 사례가 반례다.

## 오해와 교정

- 조건식 결과를 그대로 기대 결과로 쓰며 검증했다고 생각한다.
- 반례를 하나 못 찾으면 모든 입력에서 맞는 것이 증명됐다고 생각한다.
