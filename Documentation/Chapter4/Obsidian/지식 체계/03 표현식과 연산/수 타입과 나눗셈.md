# 수 타입과 나눗셈

## 한 문장 정의

Swift의 나눗셈 결과는 입력 수 타입의 계산 규칙을 따르므로 `Int / Int`와 `Double / Double`은 보존하는 결과가 다를 수 있다.

## 구분 질문

“이 문제의 결과는 온전한 단위만 필요한가, 소수 부분을 보존해야 하는가?”

## 판단 순서와 기준

1. 결과가 의미하는 대상과 단위를 말한다.
2. 소수 부분이 필요한지 판단한다.
3. 입력값의 타입을 확인한다.
4. 해당 타입의 나눗셈 결과를 예상한다.
5. 예상 결과가 문제의 목적에 맞는지 대조한다.

## 대표 예시와 경계

`5 / 2`는 `Int`끼리 계산해 정수 결과 `2`를 남긴다. `5.0 / 2.0`은 `Double` 계산으로 `2.5`를 표현할 수 있다. 책을 상자에 온전한 개수로 나누는 문제와 평균 이동 거리를 구하는 문제는 필요한 결과 의미가 다르다.

## 오해와 교정

- 오해: 수학 답이 2.5이므로 Swift도 언제나 2.5다. → 교정: 입력 타입과 연산 규칙을 확인한다.
- 오해: `Double`이 언제나 더 좋은 수 타입이다. → 교정: 온전한 단위만 필요한 문제에서는 `Int` 의미가 더 정확할 수 있다.
- 오해: 리터럴의 점만 바꾸면 문제 모델도 자동으로 맞다. → 교정: 저장할 정보와 이후 사용할 결과의 의미를 함께 설계한다.
