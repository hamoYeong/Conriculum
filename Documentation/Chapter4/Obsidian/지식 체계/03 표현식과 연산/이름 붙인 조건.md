# 이름 붙인 조건

## 한 문장 정의

이름 붙인 조건은 Bool 표현식의 판단 의미를 드러내고 다른 조건에서 다시 쓰도록 저장한 값이다.

## 구분 질문

참일 때 어떤 사실이 성립하는지 이름만으로 읽히는가?

## 판단 순서와 기준

- is·has·can 등을 포함해 구체적인 질문으로 읽히는가?
- 하나의 작은 판단에 한 이름을 붙였는가?
- 저장한 Bool이 나중에 입력을 바꾸면 자동으로 다시 계산된다고 오해하지 않는가?

## 대표 예시와 경계

- let meetsMinimum = totalCost >= 50_000
- let isEligible = meetsMinimum && isMember
- let에 저장한 Bool은 선언을 평가한 결과이며 입력 변경을 자동 관찰하는 규칙이 아니다.

## 오해와 교정

- check나 flag만으로 판단 내용을 충분히 설명했다고 생각한다.
- 이름을 붙이면 원래 기준이 무엇인지 확인할 필요가 없다고 생각한다.
