# 계산 순서

## 한 문장 정의

계산 순서는 괄호와 연산자 우선순위에 따라 표현식의 일부가 어떤 순서로 결과값이 되는지를 정한다.

## 구분 질문

“이 표현식에서 가장 먼저 하나의 값으로 접히는 부분은 어디인가?”

## 판단 순서와 기준

1. 괄호 안 표현식을 먼저 표시한다.
2. `*`, `/`를 `+`, `-`보다 먼저 찾는다.
3. 같은 우선순위의 연산은 왼쪽에서 오른쪽으로 읽는다.
4. 각 단계의 중간 결과를 하나의 값으로 바꿔 쓴다.
5. 실제 평가 순서가 문제에서 의도한 관계와 맞는지 확인한다.

## 대표 예시와 경계

`18_000 * 4 + 3_000`은 곱셈 뒤 덧셈을 평가해 배송비를 한 번 더한다. `(18_000 + 3_000) * 4`는 괄호 안 값을 먼저 만들어 배송비까지 사람 수만큼 반복한다. 결과가 같은 일부 식에서도 괄호는 의미 경계를 보여 줄 수 있다.

## 오해와 교정

- 오해: 표현식은 항상 왼쪽 기호부터 계산한다. → 교정: 괄호와 연산자 종류를 먼저 표시한다.
- 오해: 우선순위를 알면 괄호는 불필요하다. → 교정: 괄호는 사람에게 의도와 의미 단위를 명확히 전달할 수 있다.
- 오해: 최종 결과만 맞으면 순서는 중요하지 않다. → 교정: 다른 입력에서는 잘못된 순서가 다른 결과를 만들 수 있다.
