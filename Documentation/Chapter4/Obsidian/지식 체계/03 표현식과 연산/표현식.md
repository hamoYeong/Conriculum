# 표현식

## 한 문장 정의

표현식은 값, 이름과 연산을 조합해 평가하면 하나의 결과값이 되는 코드다.

## 구분 질문

“이 코드 조각을 평가했을 때 하나의 값으로 읽을 수 있는가?”

## 판단 순서와 기준

1. 표현식이 사용하는 리터럴이나 이름을 찾는다.
2. 이름이 현재 가리키는 값을 읽는다.
3. 연산과 괄호에 따라 작은 결과부터 하나의 값으로 접는다.
4. 최종 결과값과 타입을 예상한다.

## 대표 예시와 경계

`participantCount * bookPrice`는 두 이름이 가리키는 값을 곱해 하나의 결과를 만드는 표현식이다. `let bookSubtotal = participantCount * bookPrice` 전체는 표현식의 결과에 이름을 붙이는 선언이며, `bookSubtotal` 하나도 저장된 값을 읽는 표현식으로 사용할 수 있다.

## 오해와 교정

- 오해: 연산자가 있어야만 표현식이다. → 교정: 리터럴이나 값을 읽는 이름도 평가하면 하나의 값이 된다.
- 오해: 표현식은 결과와 같은 것이다. → 교정: 표현식은 결과를 만드는 코드고 평가는 실제 결과값을 얻는 과정이다.
- 오해: 실행해야만 결과를 생각할 수 있다. → 교정: 입력값과 계산 규칙으로 실행 전 결과를 예상한다.
