# 조건의 경계

## 한 문장 정의

조건의 경계는 참과 거짓이 바뀌는 기준이며 경계값 포함 여부를 따로 정해야 한다.

## 구분 질문

기준과 같은 값은 어느 쪽에 속하는가?

## 판단 순서와 기준

- 이상·이하와 초과·미만을 구분했는가?
- 경계 바로 아래·경계·바로 위를 확인했는가?
- 두 경계가 있는 범위는 양쪽을 확인했는가?

## 대표 예시와 경계

- 정수 수량 10개 이상은 count >= 10이며 9·10·11로 확인한다.
- 10개 미만은 count < 10이고 10개 이하는 count <= 10이다.

## 오해와 교정

- 보통 값 하나만 맞으면 경계도 맞다고 생각한다.
- 이상과 초과를 모두 >로 옮긴다.
