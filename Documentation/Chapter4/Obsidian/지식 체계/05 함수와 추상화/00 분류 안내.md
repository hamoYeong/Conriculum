# 함수와 추상화 분류 안내

- **다루는 질문:** 반복되는 규칙을 이름 붙인 재사용 가능한 단위로 어떻게 묶을 것인가?
- **범위:** 함수의 책임, 매개변수와 반환값, 스코프, 분해, 추상화를 다룬다.
- **인접 관계:** 입력·규칙·출력 구조를 코드로 옮기며, 프로토콜·제네릭과 앱 설계로 추상화가 확장된다.
- **확장 방향:** 한 줄 함수부터 모듈 경계까지 같은 책임과 관계의 질문으로 계속 확장한다.
