# 타입 모델링 분류 안내

- **다루는 질문:** 문제 영역의 정보와 가능한 상태를 타입으로 어떻게 정확히 표현할 것인가?
- **범위:** 구조체, 열거형, 클래스, 옵셔널, 값·참조 의미와 상태 모델링을 다룬다.
- **인접 관계:** 값과 타입의 기초를 구체화하고, 프로토콜·제네릭 및 앱 구조의 모델 설계와 연결된다.
- **확장 방향:** 단일 값에서 도메인 전체의 관계로 넓어지며 UI와 데이터 계층에도 걸친다.
