# 실행 흐름 분류 안내

- **다루는 질문:** 어떤 코드가 언제, 어떤 순서와 조건으로 실행되어야 하는가?
- **범위:** 순차 실행, 조건 분기, 반복, 조기 종료와 흐름 추적을 다룬다.
- **인접 관계:** 표현식이 판단 기준을 제공하고, 함수와 컬렉션은 흐름을 묶거나 반복할 대상을 제공한다.
- **확장 방향:** 작은 분기에서 비동기 실행 흐름까지 연결될 수 있으며 경계가 고정된 분류는 아니다.
