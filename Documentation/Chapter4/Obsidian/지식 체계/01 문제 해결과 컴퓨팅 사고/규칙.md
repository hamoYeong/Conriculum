# 규칙

## 한 문장 정의

규칙은 입력으로부터 출력을 결정하기 위해 여러 사례에 반복해서 적용하는 관계나 절차다. ^rule-definition

## 이 개념이 답하는 질문

“입력이 주어졌을 때 어떤 방법으로 출력을 결정하는가?”

## 판단할 때 사용할 질문

- 이번 사례의 값이 바뀌어도 같은 관계를 적용하는가?
- 어떤 경우에 어떤 결과를 만드는지가 드러나는가?
- 필요한 입력을 모두 사용하고 있는가?
- 규칙이 다루지 않는 경우가 남아 있는가?

## 예시

“예약 인원이 정원보다 작으면 신청을 받고, 그렇지 않으면 대기시킨다”는 여러 예약에 적용할 수 있는 규칙이다. `오늘 신청 인원 3명`은 규칙이 아니라 한 사례의 값이다.

## 자주 생기는 오해

- 계산 기호가 있어야만 규칙이라고 생각한다.
- 이번 사례의 계산 과정과 일반 규칙을 구분하지 않는다.
- 값을 그대로 내보내는 경우에는 규칙이 없다고 생각한다.
