# 문제 구조화

## 한 문장 정의

문제 구조화는 긴 설명을 해결에 필요한 정보, 관계, 결과와 경계로 나누어 다시 표현하는 사고 과정이다. ^problem-structuring-definition

## 이 개념이 답하는 질문

“이 문제를 해결 가능한 작은 판단들로 어떻게 바꿀 수 있는가?”

## 판단할 때 사용할 질문

- 무엇을 구해야 하는가?
- 무엇이 결과를 바꿀 수 있는가?
- 어떤 관계가 여러 사례에 반복되는가?
- 빠진 정보와 쓰이지 않는 정보는 무엇인가?
- 이 문제에서 책임질 범위는 어디까지인가?

## 예시

“기온과 비 여부를 보고 우산 대여 수량을 정한다”는 문제를 출력인 `대여 수량`, 결과를 바꾸는 정보인 `기온·비 여부`, 둘을 연결하는 `대여 규칙`으로 나눌 수 있다.

## 자주 생기는 오해

- 문장을 짧게 요약하는 것만으로 구조화가 끝났다고 생각한다.
- 처음부터 코드 문법으로 옮겨야 구조가 분명해진다고 생각한다.
- 모든 정보를 반드시 사용해야 한다고 생각한다.
