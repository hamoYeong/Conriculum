# 입력 규칙 출력 구조

## 한 문장 정의

입력·규칙·출력 구조는 주어진 정보가 반복 가능한 관계를 거쳐 원하는 결과가 되는 흐름을 나타낸다. ^iro-definition

## 구분 질문

“이 문제의 정보와 해결 방법, 결과는 어떻게 연결되는가?”

## 판단 순서와 기준

- 왼쪽에는 결과를 바꿀 수 있는 입력만 있는가?
- 가운데 규칙은 입력에서 출력을 결정하는가?
- 오른쪽 출력은 문제의 요구와 일치하는가?
- 각 입력의 구체적인 값과 정보의 종류를 구분했는가?
- 제외한 정보의 이유를 설명할 수 있는가?

## 대표 예시와 경계

`이동 거리 + 교통수단 → 이동 시간 규칙 → 예상 소요 시간`처럼 표현하면 값이 바뀌어도 구조의 자리는 유지된다.

## 오해와 교정

- 입력·규칙·출력을 단어 세 개로 나열하기만 한다.
- 정보의 종류와 한 사례의 구체적인 값을 별도 입력으로 중복한다.
- 화살표를 단순한 시간 순서로만 이해한다.
