# 사례를 통한 검증

## 한 문장 정의

사례를 통한 검증은 서로 다른 입력과 예상 결과를 사용해 구조와 규칙이 의도대로 작동하는지 확인하는 과정이다. ^example-validation-definition

## 이 개념이 답하는 질문

“내가 만든 구조와 규칙은 값이 달라져도 문제를 제대로 설명하는가?”

## 판단할 때 사용할 질문

- 평범한 사례에서 예상한 결과가 나오는가?
- 규칙이 갈라지는 서로 다른 경우를 모두 확인했는가?
- 필요한 정보가 빠진 사례를 알아차리는가?
- 불필요한 정보를 바꿔도 결과가 유지되는가?
- 예상 결과를 실행이나 계산 전에 먼저 적었는가?

## 예시

입장 규칙이 나이에 따라 달라진다면 기준보다 작은 값, 같은 값, 큰 값을 각각 넣어 예상 결과를 비교한다. 이름처럼 규칙에 쓰이지 않는 정보도 바꾸어 결과가 유지되는지 본다.

## 자주 생기는 오해

- 잘 되는 사례 하나만 보면 규칙이 맞다고 생각한다.
- 결과를 본 뒤 예상값을 맞추어 적는다.
- 계산 결과만 확인하고 입력이 충분한지는 확인하지 않는다.
