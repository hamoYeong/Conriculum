# 출력

## 한 문장 정의

출력은 주어진 입력에 규칙을 적용해 문제를 해결한 뒤 얻는 결과다. ^output-definition

## 이 개념이 답하는 질문

“문제를 다 풀었을 때 무엇을 새로 알거나 결정해야 하는가?”

## 판단할 때 사용할 질문

- 문제의 요구 문장이 구하라고 한 것은 무엇인가?
- 문제를 풀기 전에는 아직 정해지지 않았는가?
- 입력과 규칙을 사용한 뒤 얻는가?
- 결과가 값 하나인지, 상태나 여러 값인지 분명한가?

## 예시

좌석 수와 신청자 수로 접수 가능 여부를 판단한다면 `접수 가능 여부`가 출력이다. 좌석 수는 이미 주어진 정보이므로 출력이 아니다.

## 자주 생기는 오해

- 가장 눈에 띄는 숫자를 출력으로 고른다.
- 규칙이나 요구 문장 전체를 출력이라고 부른다.
- 출력은 반드시 숫자 하나여야 한다고 생각한다.

## 다른 지식과의 관계

출력은 [[지식 체계/01 문제 해결과 컴퓨팅 사고/입력|입력]]과 [[지식 체계/01 문제 해결과 컴퓨팅 사고/규칙|규칙]]의 관계를 확인하는 기준이다. 예상 출력은 [[지식 체계/01 문제 해결과 컴퓨팅 사고/사례를 통한 검증|사례를 통한 검증]]에서 실제 결과와 비교된다.
