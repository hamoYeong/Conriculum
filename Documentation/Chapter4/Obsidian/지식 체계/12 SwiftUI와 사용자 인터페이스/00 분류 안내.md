# SwiftUI와 사용자 인터페이스 분류 안내

- **다루는 질문:** 상태를 사용자가 보고 조작할 수 있는 화면으로 어떻게 표현할 것인가?
- **범위:** View, 상태와 바인딩, 레이아웃, 내비게이션, 접근성과 상호작용을 다룬다.
- **인접 관계:** 타입 모델링의 상태를 화면에 나타내고, 동시성·데이터·앱 구조와 함께 동작한다.
- **확장 방향:** 작은 화면 요소부터 여러 화면의 상태 흐름까지 유연하게 확장한다.
