# 학습 체계 구현 경계

이 문서는 학습 콘텐츠의 구현 계약을 현재 앱 구조에 적용한 결정 기록이다. 앱에는 하나의 학습 체계만 존재하며 소스 코드와 콘텐츠 ID에는 버전 접두사를 사용하지 않는다.

## 콘텐츠와 저장 경계

- manifest, 학습 페이지, 지식 카탈로그는 `Resources/Content`에서 독립적으로 로드하고 검증한다.
- 진행 위치, 페이지 완료, 도움 수준, 게임 응답은 `Conriculum` SwiftData 컨테이너에 저장한다.
- 학습·지식·저장 ID는 각각의 역할을 드러내는 namespace만 사용한다.

## UI 경계

- 홈은 하나의 manifest와 진행 기록만 읽고 모든 챕터 진입점을 제공한다.
- Stage 1 게임과 Stage 2 읽기 활동은 학습 목적이 다르므로 별도 SwiftUI 렌더러로 둔다.
- 글꼴, 카드 표면, 내비게이션 버튼, 워크스페이스 패널 크기 같은 시각 기반은 `Features/Shared`에서 재사용한다.
- 지식 책장은 현재 카탈로그와 완료한 페이지를 기준으로 배운 개념을 계산한다.

## 오류 경계

- 콘텐츠 로드 실패는 홈과 학습 화면에서 재시도 가능한 오류로 보여 준다.
- 저장 실패는 마지막 성공 상태를 보존하고 현재 학습 화면에서 알린다.
- 손상된 콘텐츠나 저장 레코드는 필드 경로를 포함한 검증 오류로 보고한다.
